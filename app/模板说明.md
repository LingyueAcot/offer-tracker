# 应届海投管理 · 导入模板说明

配套文件：**`导入模板.xlsx`**

把数据填进模板，回到程序点「导出 → 导入 Excel」，就能一键导入。

## 〇、已经有自己的 Excel？让 AI 帮你转（2026-09-23 新增）

不用手动搬数据，三步：

1. **拿提示词**：程序里点「导出 → 复制给 AI 的转换提示词」，
   或者打开模板里的「**给 AI 的提示词**」工作表，把「---」之间的整段复制走；
2. **发给 AI**：把「提示词 + 你自己的投递 Excel + 本模板文件」三个一起发给 外部评审 / DeepSeek；
3. **导入**：AI 会产出一个新的 xlsx，回到程序点「导出 → 导入 Excel」选中它。

提示词里已经写清：列怎么对应、日期要写成 `YYYY-MM-DD`、`一家公司多个岗位要拆成多行`、
有完整时间线时用「进展明细」怎么写，以及**「没把握的不要编造、列出来让我核对」**。
全文见 `AI转换提示词.md`（和模板里那张表是同一份内容）。

## 一、最快用法

1. 打开 `导入模板.xlsx`
2. 在「投递记录」工作表里，从第 2 行开始，**一行填一个岗位**
3. 保存后回到程序，点右上角「导出 → 导入 Excel」，选中这个文件
4. 导入是**追加**，不会删掉已有记录

示例行可以直接删掉，也可以照着改。

## 二、每一列怎么填

| 列 | 是否必填 | 说明 |
| --- | --- | --- |
| 公司 | 必填 | 公司或集团名称 |
| 类别 | 选填 | 私企 / 央国企 / 外企 / 合资 / 事业单位 / 其他 |
| 岗位 | 选填 | 岗位名称；同一家公司多个岗位，每个岗位各占一行 |
| 投递日期 | 选填 | 统一写成 `2026-09-01`（YYYY-MM-DD） |
| 投递渠道 | 选填 | 官网 / 内推 / 招聘APP / BOSS直聘 / 牛客 / 邮箱 / 其他 |
| 投递链接 | 选填 | 招聘页面链接，可留空 |
| 备注 | 选填 | 内推人、注意事项等 |
| 当前阶段 | 选填 | 只填一个当前阶段，例如 `AI测评`；留空默认「投递」 |
| 当前结果 | 选填 | 进行中 / 已完成 / 通过 / 待定 / 未通过 / 已放弃；留空时「投递」默认已完成，其他默认进行中 |
| 进展明细 | 选填 | 想一次导入完整历史时填，格式见下 |

## 三、进展明细格式

格式：`阶段|结果|日期`，多条之间用中文分号「；」隔开。

```
投递|已完成|2026-09-01；简历初筛|已完成|2026-09-03；AI测评|进行中|2026-09-05
```

- 结果只能填：进行中、已完成、通过、待定、未通过、已放弃
- 日期统一写成 `2026-09-01`
- 这一列留空时，只导入「当前阶段 / 当前结果」

## 四、宣讲会工作表（可选）

模板里第二张表叫 **「宣讲会」**，用来记校招宣讲会行程。不填也没关系，不影响投递记录导入。

| 列 | 说明 |
| --- | --- |
| 日期 | `2026-09-17` |
| 公司 | 必填 |
| 时间段 | 例如 `14:00-16:00`、`晚上`，可留空 |
| 地点 | 校区 / 楼 / 教室 |
| 现场环节 | 有笔面试 / 仅宣讲 / 待确认 |
| 状态 | 待参加 / 已参加 / 已投递 / 已面试 / 已放弃 |
| 口碑评级 | ✅ 相对正面 / ⚠️ 中等偏下 / ❌ 口碑较差，可留空 |
| 口碑/风险摘要 | 网友评价、加班、薪资、风险提示 |
| 现场必问 | 现场要问 HR 的问题 |
| 备注 | 要带的材料、交通等 |

导入后可以在程序的「宣讲会」视图里一键推进状态、按日期分组查看。

## 五、让 AI 帮你整理（重点）

如果你手上是乱格式的表格、备忘录、聊天记录，可以把它交给 AI 整理成模板。

### 方法

把下面三样东西一起发给 AI：

1. 你**自己的原始数据**（截图、表格、文字都可以）
2. 本文件 `模板说明.md`
3. `导入模板.xlsx`

### 可以直接复制给 AI 的提示词

```
你是数据整理助手。请把我提供的原始投递记录，整理成《导入模板.xlsx》里
「投递记录」工作表的结构，列依次为：
公司 / 类别 / 岗位 / 投递日期 / 投递渠道 / 投递链接 / 备注 / 当前阶段 / 当前结果 / 进展明细。

要求：
1. 日期统一写成 YYYY-MM-DD，例如 2026-09-01。
2. 类别只能填：私企、央国企、外企、合资、事业单位、其他。
3. 当前结果只能填：进行中、已完成、通过、待定、未通过、已放弃。
4. 进展明细格式：阶段|结果|日期，多条用中文分号「；」隔开。
   例如：投递|已完成|2026-09-01；简历初筛|已完成|2026-09-03；AI测评|进行中|2026-09-05
5. 同一家公司投了多个岗位，每个岗位各占一行。
6. 没有的信息留空，不要编造、不要补全不存在的经历。
7. 最后输出一个可以直接粘贴进 Excel 的表格；如果能生成 .xlsx 文件更好。

下面是我的原始数据：
（把你的数据粘贴在这里，或者上传文件/截图）
```

AI 整理好之后，把结果粘回 `导入模板.xlsx`，再用程序一键导入即可。

## 六、常见问题

**导入会覆盖我原来的数据吗？**
不会。Excel 导入是**追加**。想清空重来，用「导出 → 清空全部数据」。

**同一份文件导入两次会怎样？**
会出现重复记录，请在导入前确认。

**日期写成 2026/9/1 可以吗？**
可以，程序会尽量识别；但建议统一写成 `2026-09-01`，最不容易出错。

**一家公司多个岗位怎么办？**
每个岗位各占一行，程序会按岗位分别跟踪进展。
