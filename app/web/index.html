使用说明

快速上手

  1. 点右上角「＋ 新增投递」，填公司、岗位、投递日期。
  2. 在岗位那一行点「＋ 进展」，登记简历初筛 / AI测评 / 一面…，每次登记都会自动记下时间。
  3. 某个阶段做完了、还没开始下一阶段，点阶段旁边的小绿勾 ✓，它会变成「已完成，等待下一阶段」。
  4. 登记了新阶段后，上一阶段如果还停在「进行中」，会自动变成「已完成」。
  5. 删除会弹确认框；删错了底部还有「撤销」。

数据保存在哪

全部保存在这个程序文件夹里，不会上传到网上：

data/applications.db   主数据
data/change_log.jsonl  每一次改动（含删除）

备份：直接复制整个文件夹；换电脑：右上角「导出 → JSON 备份」，在新电脑「导入」。

批量导入（Excel）

点「导出 → 下载导入模板.xlsx」，填好后点「导出 → 导入 Excel」一键导入。 每一列怎么写、以及让 AI 帮你整理数据的提示词，见同文件夹的「模板说明.md」。

运行环境（需要装什么）

需要 Python 3.10 或更高，外加一个 pywebview（窗口外壳用它建的）： 装一次 pip install pywebview 就行。平时不需要联网（SQLite 是 Python 自带的）。

pywebview 需要系统的 WebView2 运行时：Windows 11 自带，Win10 一般随 Edge 一起装上。

两个可选功能：导入 Excel 需要 openpyxl（运行一次 pip install openpyxl）； 宣讲会自动同步 需要这台电脑装有 Chrome 或 Edge 并能联网。 这两个缺了都不影响其它功能。

出问题了 / 想反馈

程序把运行情况写在同文件夹的 logs 和 data 目录里（不会自动上传）。 遇到打不开、白屏、闪退这类问题，点下面这个按钮导出一份诊断报告， 把那个文本文件发出去就能定位问题 —— 里面有系统版本、屏幕缩放、Python 和 WebView2 版本、 最近的报错，不含你的投递记录（报告里可能带公司名，只发给你信任的人）。

导出诊断报告

个人画像（决定「对口判断」怎么算）

程序靠「个人画像」判断哪些岗位对你对口。主专业是必填的， 副专业、想去的城市、目标岗位都可以以后再补。填一次就够，之后随时能在首页改。

画像存在同文件夹的 个人画像.json 里，只在你自己的电脑上，不会上传。 想手改也行（里面的 major_keywords 是关键词，留空的话程序会按专业自动生成）。

以后更新

更新时只替换程序文件（launcher.py、server.py、core、services、api 和 web 文件夹）， 保留 data 和 个人画像.json，数据不会丢。
