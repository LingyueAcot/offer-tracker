# 应届海投管理 · 使用说明（桌面版）

## 一、怎么打开

双击桌面上的 **应届海投管理** 图标就行。

它会自己做完这几件事，你什么都不用管：

1. 后台把程序跑起来（**不会出现黑色命令行窗口**）
2. 先显示一个**启动画面**（📮 + 「正在启动…」），几秒后自动切到真实界面
3. 弹出一个独立窗口——**连系统标题栏都没有**，最上面那条是你自己的（见下）
4. 已经开着的时候再点一次图标，只会把窗口找回来，**不会重复启动、也不会多开窗口**

**关掉窗口，程序就自己退出了**（等十几秒），不会在后台偷偷占着。

> 如果窗口关了但你想马上确认一下：任务管理器里不该再有 python 进程。

### 窗口最上面那条（自绘标题栏）

```
📮 应届海投 | [搜索框] | 导出  ＋新增投递 | ─ □ ✕
```

| 位置 | 干什么 |
| --- | --- |
| 左侧品牌 | 按住它（或标题栏任意空白处）**拖动窗口** |
| 中间的搜索框 | 就是原来的搜索框，一直在那儿 |
| 导出 / ＋新增投递 | 就是原来顶栏那两个按钮，搬到这儿来了 |
| 最右边 `─` `□` | 最小化、最大化／还原 |
| 最右边 `✕` | 关闭程序（点了就退，和关窗口一样） |

> 记住一点就行：**拖动条是标题栏的空白处**。按钮和搜索框上按住是不会拖窗口的。

## 二、界面怎么用

左边一条竖着的导航，右边是干活的地方：

| 导航 | 干什么用 |
| --- | --- |
| ▣ **首页** | 「今天该干什么」+ 数据总览图表 |
| ▤ **投递** | 主战场：按公司分组的投递列表，登记进展、看时间线 |
| ▥ **看板** | 按状态分区：Offer / 投递进程中 / 已拒绝，每区里横向铺开 |
| ▦ **宣讲会** | 近期宣讲会行程（默认往后 30 天，可在 `config.json` 的 `talk_sync_days` 改）、口碑、对口判断、调研 |

底部还有三个：🌙 主题（深色/浅色）、📖 说明、⏻ 退出。

顶栏永远只有一个搜索框和两个按钮——**搜索框一直在那儿**：你在首页或宣讲会里直接打字，
它会自动跳到「投递」并开始筛选。这就是你做这个工具最初想要的东西：
**想查某家公司投过没有，直接打字就行。**

## 三、首页「今天该干什么」

打开程序第一眼看到的就是这里，三块：

1. **今明两天的宣讲会**——时间、公司、对口等级、口碑、地点，点一下直接看详情
2. **备忘录**——上半截是自动汇总的「⏳ 进行中」，下半截是你自己写的备忘；
   想到什么随手记一句，比如「给华为 HR 发邮件问进度」，办完了打勾，
   写错了点 ✎ 改，不要了点 ✕ 删，回车就能添加
3. 底部一行灰字——还有几家没调研、多少条投递很久没更新

### 「⏳ 进行中」是什么

它把**还悬着、有时效性**的投递进展自动列出来，就是为了让你不要错过——
比如 AI测评 做完了要等结果、一面过了要等下一轮通知、Offer 到手有时限。

规则（都是自动的，你不用维护）：

- **收录**：所有「进行中」的进展，但**不收录**「投递」和「简历初筛」
  ——投出去的简历一大半会停在初筛，全列出来会把首页刷屏
- **排序**：**悬得最久的排最上面**。等得越久越可能被错过，所以不按"最新"排
- **颜色**：超过 3 天变橙色、超过 7 天变红色，提醒你该催一催了
- **点一下**：跳到「投递」列表，清掉筛选条件、展开那一条并滚到它上面
  （清筛选是故意的——万一那条正好被筛掉了，跳过去会是一片空白）
- 最多显示 5 条，多出来的会提示「还有 N 条，去投递看全部」

> 它是**只读**的，不能打勾。要让它消失，就去「投递」里把那一条的阶段推进
> （比如点小绿勾、或者登记下一阶段），或者标成「已拒绝 / 已放弃」。

> 关于「停滞提醒」：**故意做得不显眼**。因为大部分投递本来就是停着的，
> 把它做成醒目的提醒，只会每天打开先被吓一下。所以它只是一行灰字，想看才看。

## 四、快捷键（桌面程序该有的手感）

| 按键 | 作用 |
| --- | --- |
| `N` | 新增投递 |
| `/` | 光标跳到搜索框 |
| `1` ~ `4` | 依次切换 首页 / 投递 / 看板 / 宣讲会 |
| `Esc` | 关闭弹窗 |
| `Ctrl + Enter` | 在弹窗里保存 |

## 五、数据在哪、怎么备份

全部在你这个文件夹里，不上传、不联网（除非你自己点「同步宣讲会」）：

```
data/applications.db     全部投递、进展、宣讲会、备忘录
data/change_log.jsonl    每一次改动，包括删除前的完整数据
```

**程序每次启动都会自动备份一份**，放在 `data/backups/<时间戳>/` 里（不覆盖、不自动清理）。

**手动备份：直接复制整个文件夹。**
换电脑：拷过去，双击快捷方式就能继续用。
`data/backups/` 觉得占地方了可以整个删掉，不影响使用。

## 六、出问题了怎么办

| 现象 | 怎么办 |
| --- | --- |
| 双击图标没反应 | 打开 `logs/launcher.log` 看最后几行；或双击 `启动（调试窗口）.cmd`，它会保留命令行输出 |
| 窗口里说「还没连上本地程序」 | 关掉窗口重新双击图标；程序会重新起 |
| 同步宣讲会失败 | 检查能不能上网；同步要用 Edge 或 Chrome 渲染页面，两者至少要有一个 |
| 导入 Excel 报「缺少 openpyxl」 | 先看提示里那个**后端解释器路径**：2026-09-28 修过一次「程序挑了个没装依赖的 Python 去跑后端」。最简单的办法是**关掉程序、重新双击 `启动.cmd`**（它会自动把缺的装上）；也可以在命令行运行 `"<那个路径>" -m pip install openpyxl`（只有 Excel 导入需要它，其它功能不受影响） |
| 想彻底重来 | 备份 `data` 文件夹后删掉它，重新双击图标，会建一个空的新库 |
| 拖不动窗口 | 按住**标题栏的空白处**拖（按钮和搜索框上按住是拖不动的）。如果标题栏上出现红色「外壳控制端口缺失」，说明外壳没接好，去看 `logs/launcher.log` |
| 窗口跑到屏幕外、或者变得很小 | 删掉 `data\window_state.json`（记录窗口位置大小的文件，只有几十字节），重新打开就会回到默认的位置和大小。程序本来就会自己判断位置是否合理，只有在记录被写坏时才会出这个问题 |
| 接了两块屏 / 缩放不是 100% | 2026-09-27 修过一次：窗口的位置和大小现在按**物理像素**算（在此之前会被系统缩放**再放大一遍**，窗口比屏幕还大、右上角的按钮落到副屏上，看着就是"拖不动、最小化点不动"）。如果还遇到：**双击 `启动（安全模式）.cmd`**（带系统标题栏，一定能用、数据不受影响），再把程序里导出的「诊断报告」发我 —— 报告里有 DPI 感知级别、真实缩放、每块屏的可用区域 |
| 窗口顶部多了一道黑框 | 2026-09-22 修过一次（原因是最小化把状态写坏、加上窗口一开始就最大化）。如果还遇到，关掉重开一次；仍然复现请把 `logs/launcher.log` 最后几行给我 |
| 想要回带系统标题栏的老样子 | 打开 `config.json`，把 `"window_mode": "borderless"` 改成 `"app"`（带系统标题栏），或者把 `"shell"` 改成 `"browser"`（完全退回 Edge `--app` 那一套） |
| 想要全屏无边框 | `config.json` 里把 `"window_mode"` 改成 `"kiosk"`，退出点左下角的 ⏻ 或按 Alt+F4 |

> 想看更细的技术说明（每个文件干什么、接口长什么样），看同目录的
> `开发记录` 和 `数据接口说明.md`。
