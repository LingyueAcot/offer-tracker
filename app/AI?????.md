# 给 AI 的转换提示词 —— 把我自己的投递 Excel 变成「导入模板」的格式

> **怎么用**：把下面「---」之间的整段复制给 AI（外部评审 / DeepSeek / ChatGPT 都行），
> 同时发给它两个文件：① **你自己的投递 Excel**；② 本程序「导出 → 下载导入模板.xlsx」拿到的模板。
> 程序里「导出 → 复制给 AI 的转换提示词」可以一键复制这一段。
>
> 它产出的是一个新 xlsx，回到程序「导出 → 导入 Excel」选中它就完事了。

---

你是一个数据整理助手。我会给你两个文件：

1. **我的表**：我自己维护的投递记录 Excel —— 列名、日期写法、记录习惯都可能和模板不一样，
   甚至可能一个表里混着好几类信息（投递、宣讲会、面试安排…）。
2. **模板**：目标格式。里面的「投递记录」「宣讲会」两张工作表定义了要哪些列、怎么写。

请把「我的表」里的数据转换进「模板」的格式，**输出一个新的 .xlsx 文件**。

## 一、硬性要求（照做，别自由发挥）

1. 输出必须是 **.xlsx**；工作表名逐字用「投递记录」和「宣讲会」，不要改名、不要多加数据表。
2. 表头**逐字**照抄模板第 1 行：不要新增列、不要改列名、不要调整列的先后顺序。
3. **一行 = 一个岗位**。同一家公司投了多个岗位就拆成多行，公司名重复没关系（不要合并单元格）。
4. 「投递日期」一律写成文本 `YYYY-MM-DD`（例如 `2026-09-01`）。
   - `2026/9/1`、`9月1日`、`20260901`、Excel 日期序列号、只有年和月…请**换算**成上面这种写法；
   - 实在认不出就**留空**，不要猜。
5. **没有的信息一律留空，绝对不要编造**公司名、日期、岗位、链接、备注。
6. 模板里那两行以「示例：」开头的是样例，**输出里不要保留**；空行也删掉。
7. 只处理数据：不要写公式、不要加颜色和边框（模板原有的表头样式可以保留）。

## 二、「当前阶段 / 当前结果 / 进展明细」怎么填

- 我的表里**只有当前进度**（比如「已投递」「一面中」「已挂」「拿到 offer」）→ 填两列：
  - 「当前阶段」写阶段名（如 `一面`、`AI测评`、`Offer`）；
  - 「当前结果」写 `进行中` / `已完成` / `通过` / `未通过` / `已拒绝` / `已放弃` 之一
    —— 按语义对应，拿不准就写 `进行中`。
- 我的表里**有完整时间线**（把投递→测评→面试一路记下来了）→ 用「进展明细」一列，语法是：

  ```
  阶段|结果|日期；阶段|结果|日期
  ```

  - 多条之间用中文分号 `；`（英文 `;` 或换行也行）；
  - 日期可以省略（省略=用这一行的投递日期），结果也可以省略（省略按 `进行中`）；
  - 例：`投递|已完成|2026-06-13；AI测评|进行中`
- **两样都填了以「进展明细」为准**；只填了「当前阶段/当前结果」就按上面第一条来。
- 「投递」这一步如果没写结果，程序会自己当成「已完成」——你不用特意补。

## 三、「宣讲会」那张表（可选）

- 我的表里如果有宣讲会 / 宣讲行程 / 双选会，转到「宣讲会」表；**没有就只留表头、不填数据**。
- 「状态」写 `待参加` / `已参加` / `已投递` / `已面试` / `已放弃` / `已过期` / `已取消` 之一，
  拿不准就写 `待参加`；「日期」同样写成 `YYYY-MM-DD`。
- 口碑、摘要、现场必问这些我没有的就留空。

## 四、做完之后附一段说明给我（重要）

在**回复文字里**（不要写进 xlsx）列出三件事：

1. **「我的列 → 模板列」的对应关系**：哪一列映射到哪一列、哪一列被丢掉、为什么；
2. **你没能对应上的行或字段**：比如某行没有公司名、某个日期认不出、某个岗位分不清属于哪家公司，
   逐条列出来让我核对；
3. 一共转换了多少行（投递 / 宣讲会各多少）。
